# Security Policy

## Supported Versions

We provide security fixes and maintenance updates for the latest release on the `main` branch.

| Version | Supported |
|:---|:---:|
| `main` (Latest) | Yes |
| Prior tags | No |

---

## Reporting a Vulnerability

If you discover a security vulnerability or critical issue affecting UltraLOB (e.g., protocol deserialization flaw, memory corruption, or denial-of-service vulnerability):

1. **Do not open a public issue.**
2. Send an email to **[rammittal0111@gmail.com](mailto:rammittal0111@gmail.com)** with the subject line:  
   `[UltraLOB Security] Vulnerability Report`
3. Please include:
   * Description of the vulnerability.
   * Reproduction steps or proof-of-concept code.
   * Assessment of potential impact.

### Response Timeline
* **Initial Acknowledgment**: Within 48 hours.
* **Triage & Remediation Plan**: Within 7 business days.
* **Public Disclosure**: Coordinated after the fix has been committed and verified.
